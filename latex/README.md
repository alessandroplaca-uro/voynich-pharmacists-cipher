# LaTeX Sources

LaTeX source files for the papers in this repository.

- `pharmacists_cipher_v2.0.tex` — preprint v2.0 (July 2026, current;
  DOI 10.5281/zenodo.21629904)
- `companion_paper_v2.0_status.tex` — companion status report and partial
  retraction v2.0 (July 2026; DOI 10.5281/zenodo.21629182)

Both compile with `pdflatex` (two passes). Sources for v1.1/v1.2 were not
archived in this repository; the published PDFs are at the repository root
and in `archive/versions/`.
